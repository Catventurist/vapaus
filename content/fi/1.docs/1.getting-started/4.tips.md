## Bun-komennot
 
Komentokehote

- `bunx nuxt typecheck` check types
- `bunx nuxi cleanup` cache & `/.nuxt/` clearing
- `bun update --interactive` to choose which depencies to update
- `bun why zod` which dependency pulled the package
- `bun audit` look for security vunerabilities
- `bun info` metadata for registries
- `bun pm pkg set author = 'Cat, Kitten'` modify `package.json`
- `bun pm version` update package version to new release

Työkaluja

- `import data from './data.yml'` YML imports
- `import { sql, SQL } from 'bun'` Postgres, MySQL, SQLite
- `import { redis } form 'bun` Key Value stores
