## Pikaisesti

Uusi projekti alkuun:

```bash [Terminal]
npx nuxi init -t github:nuxt-ui-templates/saas
```

tai luo GitHubiin kirjasto:

1. Avaa <https://github.com/nuxt-ui-templates/saas>
2. Klikkaa `Use this template`
3. Lisää kirjaston nimi ja valitse `Create repository from template`
4. Kloonaa uusi kirjasto
5. Asenna riippuvuudet haluamallasi paketinhallinnalla
6. Käynnistä kehityspalvelin

Se on siinä! Voit alkaa kirjoittamaan dokumentaatiota [`content/`](https://content.nuxt.com/usage/content-directory)-kansioon
